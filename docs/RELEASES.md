## Generation 3 — 茜音イーライ・暁

**Status: RELEASED · v3.0**

The third generation is now the current released stage of the same voicebank line.

The release includes:
- cleaned and rechecked existing material;
- new append / expression recordings;
- additional extras and non-lyrical material;
- repaired or expanded aliases where needed;
- updated OpenUtau / UTAU configuration;
- fixed comparison phrases for regression testing;
- release documentation;
- a generation-specific visual presentation.

## Development philosophy

A new generation does not erase the previous one. The voicebank grows by accumulating new ways to hear and use the same creative project.

## Revision numbering

### 1.x — maintenance

Compatibility and repair releases within an established generation.

### 2.x — major expansion

Substantial expansion of an established generation.

### 3.x — 暁 generation

The recording and presentation stage represented by **茜音イーライ・暁 v3.0**.

Earlier releases remain archived and usable while Generation 3 becomes the current reference.
